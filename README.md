# عربية الفول

لعبة متصفح مصرية: تبدأ بعربية فول خشب في حارة شعبية، وتكبرها لحد ما تفتح مطاعم في التجمع وأكتوبر وزايد.

## التشغيل
- افتح `index.html` في أي متصفح، أو فعّل GitHub Pages من Settings ← Pages ← Branch: `main` / `(root)`.
- التقدّم بيتحفظ على الجهاز، ومن "كود الحفظ" تقدر تنقله لجهاز تاني.
